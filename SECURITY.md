## Reporting a concern

Please email the maintainers privately if you find a credential exposure, an accidentally published restricted artifact, a problem with the release boundary, or a security issue in the public evaluation materials. Include the affected file or version, a concise description, and the minimum information needed to investigate. Do not post payloads, credentials, affiliation documents, or private reports in public Issues.

Use GitHub Issues for ordinary documentation errors and questions about already-public results. For artifact access, see the [release policy](RELEASE_POLICY.md).
