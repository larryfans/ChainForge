# Workspace evaluation materials

This directory retains legacy validation code for the synthetic workspace environment. Operational tool-generation and payload-instantiation instructions have been removed from the current public tree under the [release policy](../RELEASE_POLICY.md).

For the reported metrics, error handling, and repetition units, see [evaluation/PROTOCOL.md](../evaluation/PROTOCOL.md). To view the published additional-defense results without model calls, run `python3 analysis/summarize_results.py` from the repository root.

The retained legacy validators depend on historical layout and generated artifacts and are not presented as a verified standalone reproduction entry point. Runnable sanitized defense adaptations remain in preparation; see [defenses/README.md](../defenses/README.md).
